# Data_Driven_Business_Growth
# Eコマースにおける収益最大化・コスト最適化のためのデータ分析

## 概要

このプロジェクトは、仮想のECサイトデータ（顧客情報と購買履歴）を用いて、収益の向上とコストの最適化をKGI（重要目標達成指標）とするデータ分析を実施し、具体的なビジネスアクションと投資対効果（ROI）を伴う提案を行うことを目的としています。

分析の過程で、データ統合における重要な課題に直面しましたが、それに適切に対応し、販売トレンド、商品パフォーマンス、そしてRFM分析に基づく顧客行動の深い洞察を得ることができました。

## データセット

以下の2つのCSVファイルを使用しました。

*   `customer_details.csv`: 顧客ID、性別、年齢、tenure（顧客維持期間）などの顧客属性情報。
*   `basket_details.csv`: 顧客ID、商品ID、バスケット日付、バスケット数などの購買履歴情報。

## 分析プロセスと主要な洞察

### 1. データ準備と初期確認

*   `archive.zip`からデータファイルを抽出し、Pandas DataFrameとして読み込みました。
*   各データセットの初期構造、データ型、欠損値の有無を確認しました。

### 2. データクレンジングと前処理

*   `basket_date`列を`datetime`型に、`customer_age`列を`int`型に変換しました。
*   `customer_df`と`basket_df`を`customer_id`で結合を試みました。

### 3. データ統合の課題と対応

*   `customer_id`をキーとしたデータフレームの結合において、15,000行あった`basket_df`がわずか72行の`merged_df`に激減するという深刻なデータ不整合が判明しました。
*   この課題から、`customer_df`と`basket_df`の`customer_id`間に高い共通性がなく、顧客属性と購買履歴を紐付けた広範な分析は困難であると判断しました。
*   分析方針を転換し、`basket_df`に焦点を当てた販売・商品分析と、`customer_df`を独立した顧客属性の全体像把握に留める戦略をとりました。
*   `basket_df`には日付関連の特徴量（年、月、曜日）を追加し、`japanize-matplotlib`を導入してグラフの日本語表示に対応しました。

### 4. 販売トレンドと商品パフォーマンス分析

`basket_df`のみを用いて、以下の分析を行いました。

*   **月ごとの合計販売数トレンド**: 特定の月（例：5月）に販売のピークがあることを確認し、季節性の存在を示唆しました。
*   **曜日ごとの合計販売数**: 特定の曜日（例：月曜日）に販売が活発である傾向を特定しました。
*   **販売数上位10商品**: 顧客からの需要が高い人気商品を特定し、在庫管理やプロモーションの最適化の必要性を確認しました。

### 5. RFM (Recency, Frequency, Monetary) 分析

顧客の購買行動パターンをより深く理解するため、RFM分析を実施しました。

*   **Recency**: ほとんどの顧客が比較的最近（平均18日以内）に購入していることが判明。
*   **Frequency**: 平均1.08回と非常に低く、**多くの顧客が一度しか購入していない**可能性が高いことが判明。
*   **Monetary**: 平均2.32点と低く、**一度の購入で買う商品の点数が少ない**傾向を特定。

RFM分析の結果から、低い購入頻度と平均購入点数（AOV）が収益最大化の主要なボトルネックであることが明らかになりました。

## 提案と具体的なアクション

上記の分析結果と洞察に基づき、収益向上とコスト最適化のための具体的な提案と、現場でのアクション、および期待される投資対効果（ROI）を提示します。

### 提案1: 季節性・曜日性に合わせたプロモーションと在庫管理の最適化

*   **課題**: 販売数が低い期間や曜日の販売機会損失。
*   **アクション**: 特定期間/曜日に特化したセール、人気商品の積極的プロモーション、需要予測に基づく在庫調整。
*   **期待効果**: 全体の販売数増加、販売機会損失の防止。

### 提案2: 人気商品の販売戦略と関連商品のクロスセル強化

*   **課題**: 人気商品をフックとした顧客単価（AOV）向上の機会損失。
*   **アクション**: 「ついで買い」促進、バンドル販売の導入、スタッフへの推奨販売トレーニング。
*   **期待効果**: 顧客あたりの購入単価向上、売上増加。

### 提案3: データ連携の改善と顧客データ活用基盤の構築

*   **課題**: 顧客属性と購買履歴の紐付けが困難であり、パーソナライズ戦略ができない。
*   **アクション**: データ提供元への連携依頼、データ統合基盤の要件定義、顧客属性データ収集の強化。
*   **期待効果**: 顧客LTV向上、パーソナライズされたマーケティングによるコンバージョン率増加（中長期的な投資）。

### 提案4: 新規顧客のリピート化促進と離反防止キャンペーン

*   **課題**: 低い購入頻度とリピート率。
*   **アクション**: 初回購入者向けサンキュークーポン、商品推奨メール、離反危険顧客へのプッシュ通知/DM。
*   **期待効果**: リピート率向上、離反抑制、顧客LTV向上。

### 提案5: 平均購入点数（AOV）向上施策

*   **課題**: 顧客あたりの平均購入点数が少ない。
*   **アクション**: 購入点数に応じた割引制度、テーマ別商品セットの提案、「あと〇〇円で送料無料」の表示。
*   **期待効果**: 平均購入点数増加、顧客あたりの平均購入金額増加、直接的な売上向上。

## 今後の展望

*   **データ不整合の根本原因解明**: `customer_id`の不整合について、データ提供元との連携を通じて原因を特定し、データ統合の改善を図ります。
*   **ROIの具体的な数値化**: 各提案の期待効果とコストについて、実際のビジネスデータに基づいて具体的な数値を算出し、より精度の高いROI分析を行います。
*   **商品マスターデータの統合**: `product_id`に対応する商品名やカテゴリ情報を取得し、より詳細な商品分析（例：カテゴリごとの売上貢献度、商品間の関連性分析）を可能にします。
